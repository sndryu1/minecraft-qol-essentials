# minecraft-qol-essentials

Minecraft Java Edition 用の軽量な便利コマンド集データパック。

## 導入
`minecraft-qol-essentials` フォルダをワールドの `datapacks/` に入れ、`/reload` を実行。

## コマンド
| コマンド | 内容 |
|---|---|
| `/function qol:help` | 一覧表示 |
| `/function qol:day` | 昼にする |
| `/function qol:clear_weather` | 晴れにする |
| `/function qol:nv` | 暗視 (10分) |
| `/function qol:feed` | 満腹・回復 |
| `/function qol:kill_items` | ドロップ品を全て消す |
| `/function qol:gather_items` | 100ブロック以内のドロップ品を自分の位置へ |
| `/function qol:keep_inv_on` / `keep_inv_off` | 死亡時の持ち物保持 |

対応: 1.21 以降 (pack_format 48+)。
